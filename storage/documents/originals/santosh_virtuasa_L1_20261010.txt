Answer 15:
Question:
- How can I use **AWS Textract** in Python code for extracting text from a scanned PDF?

Answer:
- I can upload the scanned PDF to **Amazon S3**, start an asynchronous **Textract** job, and then read the extracted text from the job result.

**First, I upload the PDF**
- In a **FastAPI** endpoint, I receive the file and upload it to S3 using **boto3**.
- For production, I keep the bucket name and AWS region in environment variables, not directly in code.

**Then, I start Textract**
- For a scanned PDF, I use **StartDocumentTextDetection**, because PDF processing is asynchronous.
- The API returns a **JobId**, which I use to check the processing status.

```python
import boto3
from fastapi import FastAPI, UploadFile, File

app = FastAPI()

s3 = boto3.client("s3", region_name="us-east-1")
textract = boto3.client("textract", region_name="us-east-1")

BUCKET = "my-document-bucket"

@app.post("/extract-text")
async def extract_text(file: UploadFile = File(...)):
    key = f"uploads/{file.filename}"

    # Store scanned PDF in S3
    s3.upload_fileobj(file.file, BUCKET, key)

    # Start asynchronous OCR job
    response = textract.start_document_text_detection(
        DocumentLocation={
            "S3Object": {
                "Bucket": BUCKET,
                "Name": key
            }
        }
    )

    job_id = response["JobId"]
```

Answer:

**First, we detect the table region**

- I run **Camelot** with `flavor="lattice"` on that page, because the table has visible cell borders.
- Camelot returns the table data and also its **bounding box**, meaning the table coordinates on the page.
- So now system knows, for example, this rectangle is table area and remaining page area is normal text.

```python
import camelot

tables = camelot.read_pdf(
    "report.pdf",
    pages="1",
    flavor="lattice"
)

table = tables[0]
table_data = table.df
table_bbox = table._bbox
```

**Then I extract normal text**

- Using **PyMuPDF**, I extract text as individual blocks or words with their coordinates, not only as one complete string.
- For every text block, I check whether its coordinates are inside the table bounding box.
- If it is inside table area, I skip it from normal text extraction. Otherwise, I keep it as page text.

```python
import fitz

document = fitz.open("report.pdf")
page = document[0]

table_x1, table_y1, table_x2, table_y2 = table_bbox
normal_text = []

for block in page.get_text("blocks"):
    x1, y1, x2, y2, text = block[:5]

    # Skip blocks falling inside detected table region
    inside_table = (
        x1 >= table_x1 and
        y1 >= table_y1 and
        x2 <= table_x2 and
        y2 <= table_y2
    )

    if not inside_table:
        normal_text.append(text)
```

**One important coordinate check**

- **Camelot** and **PyMuPDF** can represent PDF coordinates differently, especially for the vertical axis.
- So before applying the filter, I normalize the coordinates using the page height and verify it with one sample page.
- Otherwise, table bounding box can be correct but exclusion can happen in the wrong location.

**Finally, I combine both outputs**

- From PyMuPDF, I keep headings, paragraphs, and other normal page text.
- From Camelot, I keep structured table rows and columns as a **Pandas DataFrame**.
- Then I combine them in page order, like: paragraph, table, next paragraph, so table content is not duplicated.

**So the main point is**

- **Camelot** identifies and extracts the bordered table region.
- **PyMuPDF** extracts text using coordinates.
- The table **bounding box** is used as an exclusion area for PyMuPDF.
